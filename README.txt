FLORA AYITI — CLEAN REBUILD

This version restores the green botanical interface from the preferred mockup.
It does NOT use broad image search at runtime. Plant images are curated exact Wikimedia Commons file URLs stored in plants.json.
The image policy for this prototype is plant-only: no portraits, farmers, gardeners or people are intentionally selected.

FILES
- index.html
- style.css
- script.js
- plants.json

HOW TO UPDATE ON GITHUB
1. Open the Flora-Ayiti repository.
2. Replace index.html, style.css, script.js and plants.json with these four files.
3. Keep the repository branch as main.
4. Wait for GitHub Pages to rebuild, then hard-refresh the site.

NOTES
- Scientific names are not translated.
- Plant uses are shown in Kreyòl, French and English.
- Cocoa includes Chokola peyi as a documented traditional Haitian use in the demonstration record.
- Image URLs point to specific Wikimedia Commons files rather than search results, reducing mismatches.
- Wikimedia Commons images have individual licenses and attribution requirements. Check each file page before final publication and add formal credits if required.
- All plant records and uses are demonstration data and should be scientifically reviewed before authoritative publication.
